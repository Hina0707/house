# 우리 동네 집값 변화 보기

국토교통부 아파트 매매 실거래가를 조회하는 반응형 웹앱입니다. 화면은 HTML·CSS·자바스크립트, API는 Vercel Node.js 함수로 구성합니다.

## 실행

1. `npm install`로 패키지를 설치합니다.
2. `.env.example`을 `.env.local`로 복사합니다.
3. `.env.local`의 `MOLIT_KEY`에 공공데이터포털의 Decoding 인증키를 넣습니다.
4. `npm run dev`를 실행하고 `http://localhost:3001`에 접속합니다.

## Vercel 배포

1. 이 저장소를 Vercel의 새 프로젝트로 가져옵니다.
2. Framework Preset은 **Other**, Root Directory는 저장소 루트로 설정합니다.
3. 별도 빌드 명령은 필요하지 않습니다. Output Directory는 기본값을 사용합니다.
4. Environment Variables에 **MOLIT_KEY**를 추가하고 Decoding 인증키를 값으로 넣습니다. Production과 사용할 Preview 환경에 적용합니다.
5. 배포 후 `/api/trades?region=11680&end=202610&months=3`에서 JSON 응답을 확인할 수 있습니다.
6. 배포 후 환경변수를 변경했다면 재배포합니다.

인증키는 `.env.local`에만 보관하고 GitHub에 올리지 않습니다. 이 파일은 `.gitignore`에서 제외합니다. 공공데이터포털에서 아래 API의 활용신청 승인이 필요합니다.

## 기능

- 지역과 계약월, 최근 3·6·12개월 조회
- 서울 전체 자치구와 주요 지역 빠른 선택, 목록에 없는 지역은 법정동 코드 앞 5자리로 조회
- 전용면적과 아파트별 필터
- 월별 평균·중위 거래금액 그래프, 키보드로 확인 가능한 그래프 점과 월별 수치 표
- 기준월 중위금액·평균금액·거래건수·평균 ㎡당 금액, 직전 달 대비 변화
- 최근 거래 검색, 정렬, 페이지 이동, CSV 내려받기
- 해제·취소 거래와 잘못된 금액·면적·날짜 제외
- 스마트폰 화면, 서울남산체, 마우스 효과

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구성과 입력 조건 |
| `style.css` | 반응형 디자인과 서울남산체 |
| `app.js` | 통계·그래프·필터·표·내려받기 |
| `api/trades.js` | 환경변수로 API 호출, XML 파싱, 페이지 조회, 취소 거래 제외 |
| `regions.json` | 빠른 선택 지역의 법정동 코드 |
| `server.cjs` | 화면과 API를 제공하는 로컬 개발 서버 |
| `vercel.json` | 서울 리전과 서버 함수 실행 시간 설정 |
| `.env.example` | 환경변수 이름 예시 |
| `test/app.test.cjs` | 금액·면적·결측·XML·페이지 처리 검증 |

## 통계 해석

금액의 원 단위는 API에서 제공하는 **만원**입니다. 통계 카드와 전월 대비는 선택한 기준 계약월, 면적, 아파트 조건을 사용합니다. 그래프와 목록은 조회 기간 전체를 사용합니다. 표의 검색과 정렬은 통계에 영향을 주지 않습니다.

중위값은 정렬된 거래금액의 가운데 값이며, 건수가 짝수면 가운데 두 값의 평균입니다. ㎡당 금액은 각 거래의 금액을 전용면적으로 나눈 뒤 평균합니다. 거래가 없는 달은 0원이 아닌 결측으로 처리하며, 그래프 선도 연결하지 않습니다.

월마다 거래 구성은 다를 수 있으므로 이 통계를 부동산 가격지수나 동일 주택의 상승률로 해석하지 않습니다. 최근 신고 자료는 추가·정정될 수 있습니다. API 서버는 정상 조회한 월별 자료를 최대 10분간 메모리에 보관합니다.
